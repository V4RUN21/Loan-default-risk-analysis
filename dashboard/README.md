# Power BI Dashboard

This folder is intended to contain the Power BI report file for the Loan Default Risk Analysis project.

## Dashboard Information

- **Project:** Loan Default Risk Analysis
- **Tool:** Microsoft Power BI Desktop
- **Data Source:** SQL Server database
- **Data Transformation:** Power Query Editor
- **Calculations:** DAX measures
- **Report Pages:** 3

## Report Pages

1. Loan Default and Overview
2. Applicant Demographics and Financial Profile
3. Financial Risk Metrics

## How to Open

Once the `.pbix` file is uploaded:

1. Download the Power BI report file from this repository.
2. Open Microsoft Power BI Desktop.
3. Open the downloaded `.pbix` file.
4. Configure the SQL Server connection if required.
5. Refresh the data to explore the report.

**Note:** The PBIX file has not yet been uploaded. This folder currently contains documentation only.
